# Lake Ave Labs organization profile

This public repository supplies the profile shown on [github.com/lakeave](https://github.com/lakeave).

- `profile/README.md`: the public organization introduction.
- `assets/`: the unmodified Lake Ave Labs horizontal logos for light and dark surfaces.
- `assets/README.md`: asset provenance and refresh instructions.

GitHub uses its own Markdown typography; the profile uses the official outlined SVG logos rather than live-text lettering. Absolute asset URLs ensure they resolve on both the organization page and repository preview.

This repository intentionally contains no organization-wide community-health files, issue templates or workflows. Adding those to a `.github` repository can affect other repositories in the organization.
